🐙 Git Shortcuts

  • Machine Setup: ~/dotfiles/git.sh (Global config & colors)
  • Status: gs (git status)
  • Stage Everything: gaa (git add .)
  • Stage Specific Item: ga <file> (git add file)
  • Unstage Everything: gr (git reset)
  • Unstage Specific Item: grs <file> (git reset HEAD --)
  • Commit Line: gcm "message" (git commit -m)
  • Sync: gp (git push) | gl (git pull)
  • Diff View: gd (unstaged) | gdc (staged) | gds (stat)
